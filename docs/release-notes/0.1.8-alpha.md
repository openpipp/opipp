## What changed in 0.1.8

**Calibration masters now work end to end.** Five defects in the master workflow were fixed:

- A flat-dark master is built from the engine's own `.tmp` container instead of failing with
  `NotSupportedException`; the builder reads `.tmp` through the same reader that wrote it.
- A failed build is a result, not a `-1` sentinel. The GUI shows the reason, marks the run failed and
  does **not** launch the engine or pass a master that was never written.
- A flat-dark is subtracted **exactly once**. When the GUI builds the corrected flat it no longer also
  hands the flat-dark to the engine; a user-supplied flat plus flat-dark still subtracts at processing
  time, and both paths are tested.
- RGB master darks keep their three channels: the full-fidelity `.tmp` is authoritative and the luma
  PGM is a fallback only when no `.tmp` exists.
- Cancel stops master building, not just the engine that had not started yet. A cancelled or failed
  build leaves no staging file and no publishable master.

The regression fixture runs flat `[200,100]`, flat-dark `[50,0]`, science `[125,125]` through master
creation, the files on disk and the exact switches the GUI passes, and asserts `[104,156]`. Double
subtraction produces a different result, so the test proves the handoff.

**Stacking arithmetic is now pinned.** Mean, sum and median are covered for mono/RGB at 8 and 16 bits:
exact values, saturation at 255/65535, fractional truncation, even-median half-up (documented as
distinct from mean truncation), independent RGB channels, reference subtraction before averaging, and a
32-bit overflow guard at 65,538 frames. Median no longer retains the caller's sample arrays by
reference, so a reused buffer can no longer rewrite frames already submitted. An unknown stack method
is rejected instead of producing a zero image.

**Joined inputs are bounded.** `-join` opens one reader at a time and disposes each input as it is
exhausted; a long joined PNG sequence no longer holds every compressed payload at once.

**GIF test correction.** The late-colour reservoir fixture started blue at sample 245,760, before the
262,144 cap, so it did not actually prove replacement sampling. It now starts after 270,336 samples.

## Known limits

- Median stacking retains at most **64 frames** (759 MiB for 64 RGB frames at 1920x1080). Disk-backed
  tiled median is not implemented.
- Mean/sum/median final stacking is a Core API capability; the CLI and GUI do not expose a method
  selector yet.
- A Bayer-marked selection is stacked as ordinary samples and the result carries `Bayer=None`;
  debayer first if the mosaic must be preserved.
- Master-file compatibility is pinned by native goldens built from identical inputs; unequal-frame
  native goldens that would distinguish averaging and subtraction rules are still missing.
