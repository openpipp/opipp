## What changed in 0.1.7

**0.1.6 did not start. This release fixes that.** The About box rewrite left a corrupted
`$this.Icon` entry in the main form's resources: the `.resx` still declared a BinaryFormatter
serialized `Icon`, but its payload had been replaced with raw `.ico` bytes. The project compiled and
all tests passed, then `InitializeComponent` threw `SerializationException: Invalid value:
536870912` before the window appeared. The icon now comes from the executable's own embedded icon
(the project's `ApplicationIcon`), and the resource entry is gone.

A new test constructs the real `Form1` and the real About dialog on an STA thread, so a window that
cannot be built fails the build instead of the download.

**Version numbers now have one source.** The window title and About box read the assembly's
informational version, which comes from `Directory.Build.props`. Three fields (`Version`,
`AssemblyVersion`, `FileVersion`) and every document are checked against each other in CI; a partial
bump - which shipped a 0.1.6 build whose FileVersion still said 0.1.5.0 - now fails.

**Carried over from 0.1.6**: the original project's About box, application icon, assembly metadata
and update check are gone, replaced with OPIPP's own; the GIF colour cache is bounded; cancellation
stops SER/AVI preparation promptly; spill storage is always closed; empty containers can no longer
count as parity matches.

## Verification

- **634 tests**, 0 failures, including two that construct the application windows.
- Parity: 27 compared, 27 matched, 2 deliberate differences, 0 gaps, 0 failed.
- The packaged zip is extracted and smoke-converted by the release workflow before publication, and
  the GUI was launched from the packaged build as part of this release.

## Note on earlier releases

`0.1.6` was withdrawn because it could not start. `0.1.2` to `0.1.5` were withdrawn because their
About box and icon were the original project's. This release supersedes all of them.
