## What changed in 0.1.5

**Capture metadata survives spilling.** Frames that move to the disk spill store now carry their
source path on the retained handle, so a conversion that spills still copies the SER Observer,
Telescope and Instrument fields. Previously the same capture kept its metadata in memory and lost it
once the retention budget forced a spill. A test converts a SER with metadata in-memory and with a
1-byte budget and requires the two outputs to be byte-identical.

**A bad master is an error, not a crash.** A dark or flat whose geometry does not match the capture
now prints the two shapes and exits with status 1 on both the console and `-gui` paths.

**Colour GIF memory is bounded.** The palette builder used to collect about 16,000 colours from every
frame with no global cap - roughly 165 million samples for 10,000 frames at 1920x1080. It now keeps a
deterministic 262,144-sample reservoir, which is 786 KB regardless of length. Buffered and streaming
encoders share the sampler and remain byte-identical. Output for animations larger than the cap
changes intentionally.

**Spill files are released on failure.** The store is disposed in a `finally`, and cancellation is
checked while consuming output frames as well as while reading inputs.

**Harness fixes.** Nonzero engine exits now fail the verdict, multiset comparison is genuinely
order-independent, the timeout survives blocked pipes, and unreadable output can no longer make the
harness throw. Eight fake-engine tests cover those cases.

## Known gaps

- Surface-feature tracking is exact on 23 of 30 frames of the real Saturn capture; the rest are one
  pixel off.
- 16-bit Bayer debayer is not byte-verified; `-raw_*` is not value-parity-proven.
